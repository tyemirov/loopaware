One pixel for page-level signals

The LoopAware traffic pixel is built for teams that need practical page-level analytics, not a full analytics migration. It records visits and visitor context, then feeds top pages, trends, devices, locations, and CSV export.

Small install, useful output

  • Records page URL, referrer, browser timezone, locale, viewport, screen resolution, and stable visitor ID.
  • Accepts only configured origins for the site, matching the feedback and subscriber boundaries.
  • Supports a plain image pixel fallback for environments that cannot run JavaScript.
  • Feeds selected-site and all-sites reports for operators who manage several properties.
