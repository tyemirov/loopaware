Portfolio reporting

Portfolio traffic reports for multiple sites

LoopAware supports all-sites traffic reporting for operators who manage more than one public site and need a portfolio-level summary instead of opening every site individually.

Why portfolio reports are distinct

A selected-site report answers how one site is doing. A portfolio report answers what is happening across the sites an operator can see, which is useful for owners, admins, and agencies.

Portfolio reporting should respect the same visible-site access semantics as the dashboard.

Use cases

Agency account review

See client-site traffic patterns without logging into each site one by one.

Owner operating rhythm

Keep the site portfolio visible in a recurring email summary.

Multi-product monitoring

Compare traffic movement across related sites during launches or incidents.

Limitations

  • Portfolio reports are summaries, not a replacement for site-level detail views.
  • They should not expose sites a user cannot access.
  • For single-site recipient selection, use selected-site traffic report emails.

Best fit

Use this when one operator owns or administers several sites and needs a recurring overview.
