Context turns messages into work

A message that says "this is confusing" is hard to triage without knowing the page. Source context lets a small team connect feedback to page ownership, copy, UX, and traffic patterns.

For mobile apps, use screen context through the registered mobile feedback client instead of a browser URL.

What source context helps with

Prioritization

Connect feedback to high-traffic pages or conversion-critical screens.

Routing

Send documentation issues, pricing confusion, and app flow problems to the right owner.

Reproduction

Use the originating URL as the first step in reproducing what the visitor saw.

Limitations

  • Source URLs should not include secrets or private data in query strings.
  • Context does not replace a clear message when the visitor has details to share.
  • For native apps, page URL context is not the right model.

Best fit

Use this to make visitor comments actionable for teams that operate many public pages or product flows.
