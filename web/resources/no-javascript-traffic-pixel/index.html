No-JavaScript traffic pixel fallback

LoopAware includes an image pixel fallback for pages where JavaScript is unavailable, blocked, or intentionally minimized, while the JavaScript pixel still provides richer context when it can run.

Why a fallback matters

Some sites intentionally keep scripts minimal, and some visitors block JavaScript. The fallback gives teams a basic visit signal without requiring a full client-side runtime on every page.

What changes without JavaScript

Basic request context

The image request can record the server-observable visit context.

Less browser detail

Viewport, screen, and richer client-side fields require the JavaScript pixel.

Same site dashboard

Fallback visits still support the same site-level traffic reporting surface.

Limitations

  • The image fallback cannot collect every browser detail that JavaScript can provide.
  • It is not a replacement for product event analytics.
  • Public endpoint origin and site configuration still matter.

Best fit

Use this when a site values minimal script usage but still wants a baseline traffic signal in LoopAware.
