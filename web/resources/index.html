Built as a connected surface

These pages are linked because the product is connected. A feedback spike is easier to interpret with traffic context. A subscriber campaign is clearer when the same dashboard shows page visits. A production error is easier to prioritize when it is tied to the same site operators.

Common setup path

  1. Create a site and allowed origin in the dashboard.
  2. Copy the feedback, subscribe, traffic, or LA Sentry snippet you need.
  3. Review messages, subscribers, visits, reports, and errors in one role-aware dashboard.
