How to use these guides

Start with the LoopAware signal you want to collect first, then move into the adjacent setup guide when the dashboard shows useful records.

  • Feedback guides cover web widgets, mobile apps, sentiment, source context, and multi-origin collection.
  • Subscriber guides cover capture forms, confirmation states, inline embeds, and CSV export.
  • Traffic and LA Sentry guides cover analytics, report emails, uptime checks, browser errors, server errors, and issue triage.

Built as a connected surface

These pages are linked because the product is connected. A feedback spike is easier to interpret with traffic context. A subscriber campaign is clearer when the same dashboard shows page visits. An uptime alert or production error is easier to prioritize when it is tied to the same site operators.

Common setup path

  1. Create a site and allowed origin in the dashboard.
  2. Copy the feedback, subscribe, traffic, mobile, health, or LA Sentry setup you need.
  3. Review messages, subscribers, visits, reports, uptime checks, and errors in one role-aware dashboard.
