Feedback widget appearance controls

LoopAware lets site managers adjust the feedback bubble so it fits a real page layout: accent color, side placement, bottom offset, and whether name or email fields should appear in the form.

Why appearance settings matter

A feedback button that covers a checkout control or clashes with a brand color creates friction before a visitor can send useful feedback. LoopAware keeps these changes in site settings so the widget code stays simple.

<script src="https://loopaware.mprlab.com/widget.js" data-site-id="..."></script>

What managers can tune

Accent color

Use the saved widget accent to make the bubble and send action feel native to the page.

Position

Choose the side and bottom offset so the bubble avoids chat launchers, cookie banners, and mobile nav.

Form fields

Control name and email visibility based on whether the feedback flow needs anonymous or contactable messages.

Limitations

  • Appearance controls do not change origin validation or public feedback routing.
  • Custom styling should be used to fit the page, not to hide the feedback control from users.
  • Contact fields still need clear handling under the site's privacy expectations.

Best fit

Use this when a production site needs a visible feedback entry point that avoids important UI and still feels like part of the brand.
